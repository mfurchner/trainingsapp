# TrainingsApp

Eine moderne Progressive Web App (PWA) zur Unterstützung eines 4-wöchigen Trainingsplans.

## Projektziele

Version 1.0 umfasst:

- Dashboard
- Trainingsplan
- Timer
- Statistik
- Einstellungen
- Offline-Unterstützung (PWA)
- Lokale Datenspeicherung

## Technologien

- HTML5
- CSS3
- Vanilla JavaScript (ES Modules)
- Progressive Web App (PWA)
